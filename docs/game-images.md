# Game screenshots

The site uses **one sourced screenshot in each illustrated game detail**. The four-column game index remains text-only; there are no repeated thumbnails.

## Coverage and review

180 exact game-index IDs currently have an image: the first 30 plus 150 added in the second batch (65 Atari 2600 games, 11 research environments or documented renderers, 45 commercial games and 29 original text-game interfaces). This is partial image coverage of the 1,289-entry game index, not a claim that all remaining games have been exhaustively searched. See `data/curation/game-image-review.json` for reviewed but unselected candidates.

Images show the named original game or research environment. Captions distinguish original games from adaptations, exact Atari 2600 titles, Craftium's OpenWorld and ChopTree, Craftax from Classic, and Neural MMO's historical v1.2 rendering. Machiavelli-associated screenshots show the original text game rather than a benchmark execution. A picture does not establish that every associated study uses the pictured interface, nor that an evaluation has been reproduced.

## Provenance and processing

`data/curation/game-images.json` records source type, original URLs, fixed repository revisions where available, original SHA-256 hashes, selected animation frames, processing, output hashes, bilingual captions and credits. Official store images use developer/publisher screenshots from the exact title's store page; collection and remaster mismatches are withheld. Promotional collages and title cards are not substituted for gameplay.

Optimized WebP images live under `src/assets/game-images/` and are served locally by Pages. Builds need no image-processing dependency or network. Images load lazily only in the selected game's detail. Resizing preserves aspect ratio without upscaling. Atari frames use lossless encoding. No generative images or reconstructed gameplay are used. The original ViZDoom asset uses its first demonstration panel; other images preserve the complete selected frame. Crafter retains the upstream terrain montage.

Root repository license texts, where supplied, are preserved under `src/assets/image-licenses/` and distributed with the site. Repository code licensing does not automatically relicense third-party game artwork. Official store and blog imagery retains the credited rights holders; no independent open license is asserted. Each detail links to its original source.
